## Asset processing checklist
1. Preserve original archives in `assets/source/`.
2. Inspect ZIP file listings before extracting. Avoid unsafe paths and verify asset licenses.
3. Identify mesh formats (GLB, GLTF, FBX, OBJ), materials, textures and character rigs.
4. Verify facial meshes, eyelids, mouth, teeth, eye shading and expression controls.
5. Build or repair facial rig / visemes for speech animation.
6. Record original-to-scene object mappings and units.
7. Keep large binaries in Git LFS or GitHub Releases if they exceed Git limits.
